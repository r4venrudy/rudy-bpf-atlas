# Security policy

Rudy BPF Atlas parses untrusted ELF, BTF, and BTF.ext data. Keep reports scoped to the supplied local files and run current releases. The analyzer does not load BPF programs or contact external services.

Please report a security issue privately through GitHub's **Report a vulnerability** feature on this repository. Include the affected version, a minimal input or reproduction steps, and the observed impact. Avoid posting an unpatched parser vulnerability in a public issue.
